# Halaqat Al Quran / Quran Class Manager

Android app to manage Quran classes (halaqat), students, and homework tracking.

## Requirements
- Android Studio
- JDK 11+

## Run (Debug)
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Run on a device or emulator.

## Secrets
Release signing keys and Play upload keys are kept out of git. Keep them outside
this repo and copy them in only when needed.
